把一篇论文写成公众读得懂的稿子，每一句都追得回它的出处。

SciComm Agent 读取论文，抽出一份「依据清单」，为不同平台起草， 再用另一个模型逐句核对。任何超出依据的说法都会被标出来交给人处理。

It reads a paper, extracts a claim ledger, drafts for each platform, then audits every sentence against that ledger with a different model. Anything that outruns its source is flagged for a human. It never publishes.

不会妥协的四条 The rules it will not bend

写得出，就查得到

数字、因果、程度、「首次」、「证明」——任何一句这样的话都必须对应依据清单里的一条，否则不写。

Every number, causal claim, magnitude, “first” or “proves” maps to a ledger entry, or it is not written.

限定词跟着走

物种、样本量、「初步」、相关不等于因果——起草时保留，核对时检查。

Species, sample size, “preliminary”, correlation-not-causation: carried into the prose, then checked.

不自己给自己打分

起草与核对用不同的模型、不同的提示词。两者设成同一个模型时，审稿台拒绝开工。

Drafting and checking use different models and different prompts. Set them the same and the board refuses to start.

永不自动发布

产出的是草稿、出处和存疑标记，交给人审。发布这一步永远由人来做。

The output is a draft, its provenance and its flags — for a human. Publishing is never automated.

一次运行经过什么 What one run does

  1. 01

    取全文 · fetch + extract

    链接、DOI 或 PDF。摘要页会自动升级成全文 PDF；取不到就说清楚为什么，并请你补一个 PDF。

  2. 02

    建依据清单 · claim ledger

    把论文里可引用的结论逐条抽出来，每条带上原文依据、限定词和置信度。清单是空的，就什么都不写。

  3. 03

    分平台起草 · draft

    新闻稿与小红书各有结构；语言、读者、活泼度是参数。每个事实句都标注它引用的依据编号。

  4. 04

    逐句核对 · faithfulness check

    换一个更强的模型，只对着依据清单读稿子，标出相关当因果、丢限定词、以偏概全、清单里没有的说法。

两条支线只影响文风、不提供事实：外部背景检索给起草提供叙事语境， api/styles/examples/ 里的范文会被蒸馏成语气画像。核对模型两者都看不到。

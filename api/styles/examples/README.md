# Style examples

Drop popular-science articles you like into this folder as `.md` or `.txt`.
They are **distilled** into an abstract StyleProfile (voice, rhythm, openings,
vocabulary, devices, things to avoid) — the drafter sees only that profile,
never the raw articles.

- Leave the folder empty to keep the current default drafting behavior.
- The profile layers **on top of** the platform blueprints in
  `api/styles/{news,wechat,xhs}.md`; it does not replace them.
- Voice only. Facts, numbers and subject matter are stripped during
  distillation: every number / causation / magnitude / "first" / "proves"
  statement in a draft still comes only from the claim ledger.

Article contents are gitignored (only this README and `.gitkeep` are tracked),
so copyrighted or personal material stays local.
